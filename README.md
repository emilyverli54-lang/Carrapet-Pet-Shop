# Carrapet Pet Shop
# 🐾 PetShop Web

## Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade acadêmica e consiste na criação de uma página web para um petshop fictício, com o objetivo de simular algumas das principais funcionalidades de um estabelecimento desse segmento.

A aplicação permite que o usuário navegue pela página, simule o agendamento de serviços de tosa e realize pedidos de ração por meio de formulários.

## Funcionalidades

- **Agendamento de tosa:** formulário para simular o agendamento do serviço para o pet.
- **Pedido de ração:** formulário para preencher as informações de um pedido de ração.
- **Interação com o usuário:** campos para preenchimento e envio das informações dos pedidos.
- **Interface web:** página desenvolvida para apresentar os serviços e facilitar a navegação do usuário.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Objetivo acadêmico

O projeto tem como objetivo colocar em prática os conhecimentos adquiridos durante a formação, explorando a estruturação de páginas web, a estilização de interfaces e a criação de formulários para interação com o usuário.

Também representa uma oportunidade de desenvolver habilidades em desenvolvimento front-end e compreender como funcionalidades comuns de um site comercial podem ser representadas em uma aplicação web.

## Status do projeto

Projeto acadêmico desenvolvido para fins de aprendizado e prática de desenvolvimento web.
